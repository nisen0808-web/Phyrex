## 固定约束

Migration 已发布版本不可修改；需要新结构时追加 migration。保留 revision fence、原子命令确认、请求幂等、提交后发布、重试不重复模拟、限流、审计安全字段和显式 bash/pipefail。不以跳过真实数据库、减少已有门禁或仅查看 CI 图标代替验收。

持续状态以本清单、Git 分支和真实测试证据为准。测试必须对应交付功能代码；文档收尾提交需要逐文件证明除明确列出的 Markdown 文档外没有变化，并同时记录测试提交和交付提交，不能声称两者整个 Git tree 相同。main 和已审查分支不强行改写；本轮在 feature/engine-completion 交付。

## 明确的运行边界

v1 为 PostgreSQL 单写世界运行器；规模由世界实体数量、配置容量与测量结果决定，不承诺无限人口或无界历史。分布式领导者、高可用部署、托管账户注册/找回密码和公网网关属于独立运行服务，不自动视为本地引擎必须完成的功能。管理工具必须明确其操作权限、并发冲突和安全输出行为。
