# Engine Development Progress

本文件记录引擎优先阶段的开发状态。当前主线是世界模拟和持久化可靠性，不继续扩展 UI、登录或部署功能。

## 当前阶段：数据库启动恢复

前期百分比属于各模块原定范围的估算，没有统一分母，不是自动测量的整体完成度，也不代表生产验收。尤其数据库此前的 96% 只反映 JSONL 原型及管理入口，不能代表关系数据库已经完成。本批次改用可验证里程碑记录数据库进展。

| 本轮里程碑 | 实现与验证入口 |
|---|---|
| 先前 PR #60 | 页面清单已完成两套 CI 后合并；本轮不新增页面。 |
| 启动恢复 | prepareDatabaseStartup 在 API 监听和计时器启动前读取、校验、恢复世界。 |
| 恢复策略 | off / if-present / required；多世界必须明确选择；缺失或坏存档不静默回退。 |
| 最新存档语义 | 按追加 sequence 选择；支持回滚后较小 tick 和同 tick 多次保存。 |
| 存档结构门禁 | 校验 JSON、记录类型、ID、sequence、tick、schema 和 envelope/world 一致性。 |
| 真实进程恢复测试 | 子进程恢复 tick 17，经 HTTP 推进并保存到 18；退出后第二进程恢复 18。 |
| 随机数与 ID | 新回归检查命名随机流和世界级确定性 ID 在存档恢复后的续接。 |
| 测试接入 | database-startup-recovery-test.js 纳入 npm test；最终结果以本 PR 最新 head 的 CI 为准。 |
