          下载后怎么用

          把配置交给引擎的创建工具，生成一个独立的新世界存档。此页面不会直接启动或替换线上世界。

          1. 在引擎目录建立 output 文件夹。
          2. 将下载的配置放在引擎目录。
          3. 执行下方命令，生成新文件。
          npm run engine:init -- --template-file world-template.json --template-id TEMPLATE_ID --output output/my-world.json

          然后按 ENGINE_QUICKSTART.md 将存档导入专用数据库、建立账户并启动。首次导入使用 expected-revision 0；遇到已有世界时停止。

          PHYREX ENGINE 配置仅保留在此页内存 · 下载后由你保管
